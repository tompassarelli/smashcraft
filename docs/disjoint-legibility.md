# Disjointed attack effects

A move is listed when an active region extends beyond the current hurt parts by more than half the standing body width (the standing capsule radius), along either gameplay axis. Each listed normal draws an accent at each live region’s world centre, including portions of that move that return closer to the body. Both facings are checked on every frame. Accents hold a visible pose during hitstop and do not change collision.

The named Smash moves are visual references, not copied animation assets or shared hitbox geometry.

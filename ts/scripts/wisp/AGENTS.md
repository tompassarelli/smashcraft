# Native tools

Use the selected client set’s explicit --clients-file throughout nested recovery, observation and input. WISP_CLIENTS does not select clients.
Never touch Tom’s install or account a. The offline pool is Classic only; Definitive checks use signed-in clones b, c and d.
Offline clients never construct account launchers. clone-b/c/d use their own launch script and keep their sign-in; doctor supplies no account to clones.
A crashed, desynced or prematurely ended native session is invalid; retain its result and rerun after fixing the cause.

# Evidence records

Each file or folder here is the record of one dated trial or decision: its
candidate, inputs, raw traces and result at the time. Records are immutable
history. Don't edit them to reflect later work, and don't treat them as
current guidance.

- Current status and next work: roadmap [#16](https://github.com/tompassarelli/smashcraft/issues/16) and its issues.
- Durable knowledge distilled from these records: [docs](../docs/README.md).

Name new records `<topic>-<yyyymmdd>` and link them from the issue they answer.
